## 2. 実際の画面と食い違いがないか

掲載情報・画像・動画で言っていることを、アプリの決まり（PRO_GATES、作者の決定）とテストで確かめました。

| 言っていること | 確かめたこと |
|---|---|
| 学習と日常の機能は購入しなくても使える。Pro は 3D グラフ、1,000 桁超、タンクの鏡板、輪郭から回転体、STL、表と履歴の CSV、配色テーマ、2 つ目からの計算メモ、動く GIF・透かしのない画像 | app.js の PRO_GATES（tables・tank_heads・profile・stl・share_pro・notes が pro、3D グラフと桁数と配色と履歴の書き出しは hasPro）、テスト PS09〜PS16 |
| 「⟳ 3D」で回転体と体積がすぐ出る（無料）、3D で見るのは Pro | PRO_GATES の revolution・cross_sections・rev_lines が free（3D の表示は Pro）。画像と動画の 3D の場面には「3D の表示：QCalc Pro」の印 |
| 定期購入ではない、1 回の購入 | Pro.java（買い切りのアプリ内アイテム qcalc_pro） |
| 広告がない、個人データを集めない、インターネットは為替レートだけ | プライバシーポリシー（docs/privacy.html）、マニフェストの権限（INTERNET と VIBRATE だけ。課金のある版は Google Play の課金ライブラリの権限も）、コード（アプリがネットに出すのは為替レートの取得だけ。説明書の Web の版やポリシーのリンクは外のブラウザで開く） |
| ネットなしで計算・グラフ・取扱説明書が使える | 取扱説明書はアプリの中（app/assets/manual）、テスト MN（オフラインで開く） |

| 22 の図形、容器の液量、測った断面から体積、密度から重さ | 図形の一覧（SHAPES）、テスト VS・VM・TH |
