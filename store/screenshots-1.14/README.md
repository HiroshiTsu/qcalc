# Google Play の画像（1.14.0）

1.14.0（release/1.14.0 の f8e6287）の画面から store/tools/shots.js で撮ったものです。並びは 1.12 と同じで、3D は GPU（WebGL 2）で描いた新しい見た目です。
「透明」がオンの画像（容器が透けて液体が見える）は、スマホの 5 枚目とタブレットの 5 枚目（tank-3d）です。
透明の行は、1.14.0 の直し（透明がオフでもスライダーで透明になる、「透明」と「箱と目盛り」がスイッチの形）のあとの見た目です。
