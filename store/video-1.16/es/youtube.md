## Description

```
QCalc es una calculadora para Android cuyo historial funciona como una hoja de cálculo: cada línea tiene un número, así puedes reutilizar un resultado con #12, sumar una selección o copiar líneas como tabla. Notas de cálculo con modo tabla, herramientas de bolsa como el tamaño de posición desde el stop y gráficas que se convierten en sólidos 3D con su volumen, todo en una app.

User manual: https://hiroshitsu.github.io/qcalc/manual/
Source code: https://github.com/HiroshiTsu/qcalc
Bugs and ideas: hiroshitsu.apps@gmail.com
```
