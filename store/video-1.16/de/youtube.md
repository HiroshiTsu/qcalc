## Description

```
QCalc ist ein Rechner für Android, dessen Verlauf wie eine Tabelle funktioniert: Jede Zeile bekommt eine Nummer, so kannst du ein Ergebnis als #12 wiederverwenden, eine Auswahl summieren oder Zeilen als Tabelle kopieren. Rechennotizen mit Tabellenmodus, Börsen-Tools wie die Positionsgröße aus dem Stop-Loss und Graphen, die zu 3D-Körpern mit Volumen werden, alles in einer App.

User manual: https://hiroshitsu.github.io/qcalc/manual/
Source code: https://github.com/HiroshiTsu/qcalc
Bugs and ideas: hiroshitsu.apps@gmail.com
```
