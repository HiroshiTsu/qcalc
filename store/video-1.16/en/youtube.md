## Title (97 / 100)

QCalc: a calculator whose history works like a spreadsheet (notes tables, stock tools, 3D graphs)

## Description

```
QCalc is a calculator for Android whose history works like a spreadsheet: every line gets a number, so you can reuse an answer as #12, add up a selection or copy lines as a table. Calculation notes with a table mode, stock tools such as the position size from a stop-loss, and graphs that turn into 3D solids with their volume are all in one app.

User manual: https://hiroshitsu.github.io/qcalc/manual/
Source code: https://github.com/HiroshiTsu/qcalc
Bugs and ideas: hiroshitsu.apps@gmail.com
```
