## Description

```
QCalc 是歷史紀錄直接變成試算表的 Android 計算機。歷史紀錄的每一行都有編號，可以用 #12 沿用前面的結果，選取加總、平均，或以表格複製。有表格模式的計算筆記、由停損價算出股數等股票工具，以及把圖形旋轉成 3D 立體並算出體積，都在同一個 App。

User manual: https://hiroshitsu.github.io/qcalc/manual/
Source code: https://github.com/HiroshiTsu/qcalc
Bugs and ideas: hiroshitsu.apps@gmail.com
```
