# Google Play の画像（1.15.0）

1.15.0（release/1.15.0 の a821bb2）の画面から store/tools/shots.js で撮ったものです。並びと見出しは 1.12・1.14 と同じで、答えの表示（有効桁数 15 桁・3 桁区切り・= と ≈ の 2 行）、上の「15桁」のボタン、答えの下の次の操作のボタンが 1.15.0 の見た目です。3D は GPU（WebGL 2）で描いたもので、「透明」がオンの画像は、スマホの 5 枚目とタブレットの 5 枚目（tank-3d）です。
計算メモの画像（phone-6-notes）は、その地域の通貨にしたテストのサーバーで撮りました（en USD、en-GB GBP、de・es・fr EUR、es-419 MXN、fr-CA CAD、ko KRW、zh-TW TWD、ja JPY）。
